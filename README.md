# M31 Bubble Atlas · 气泡标注台

基于本项目原始 PHAT / PHAST 消光 FITS 的在线椭圆标注工具。这个子文件夹是独立的网站工程；原始 `../data/` 和已有处理结果没有改动。

源码已更新到本 GitHub 仓库；当前仅供本地运行，**尚未发布网站**。本地地址：http://127.0.0.1:5173/ 。待提供服务器信息并确认后再部署。

## 使用

1. 打开网站，点击「选择用户名」，创建名字或选择现有名字。**不需要密码，也不需要 ChatGPT 账户**。用户名是公开的标注分组，不是私密身份；任何人都能浏览或选择同一用户名继续编辑。
2. 侧栏展示所有参与者与气泡数。点击其他参与者会进入只读浏览；要编辑，点击「使用此用户名」。每个用户名的目录分别保存。
3. 滚轮缩放；在空白处拖动平移。点击「添加圆」在视图中心添加圆，或点击「拖绘」从中心向外拖出一个圆。
4. 拖动椭圆本身移动；椭圆使用黑色 1 像素细线。两个方形轴手柄调整长宽，右下角方形手柄等比缩放，顶部圆形手柄旋转。也可以在右栏直接输入 RA、Dec、角秒半轴与天球 PA。
5. 点击「确认并保存」。以前保存的椭圆会保留。点击地图或目录中的气泡可重新选中、修改、删除。未确认修改会在离开时提示。
6. 「标注可见」可隐藏/显示当前目录的所有椭圆；未选中椭圆不显示名称，另有选中名称开关、天球网格、RA/Dec 跳转和视图 PNG 导出。

同一用户名在两个页面编辑同一记录时，服务端通过 `revision` 检查冲突，拒绝覆盖较新的记录；刷新当前目录后再调整。切换用户名后的旧页面也不能误写到新用户名。

## 用户名重命名与删除

点击右上角用户名打开名单，再点击「管理当前用户」。如需管理另一个用户名，先选择该用户名。

- 重命名：输入新用户名并保存，原有标注、坐标与用户 ID 保留；名称不可与其他用户重名。
- 删除：先导出需要保留的目录，再在确认框输入当前完整用户名，点击「永久删除用户及全部标注」。该操作同时清理该用户的标注和所有会话，不影响其他用户。
- 操作期间不可重复提交；名单在其他页面变更时会提示刷新。用户名仍然是无密码的公开分组。

## 实时颜色设置

地图底部提供独立的显示控制，修改后立即重新着色，不改变标注参数或原始数据：

- 下限与上限：数值输入或连续滑块，单位 mag；「自动范围」取原始地图 1%–99% 分位数。
- **Linear**：线性归一化。
- **Log**：`log(1 + k*t) / log(1+k)`，其中 `t` 是上下限间的归一化数值，`k` 可调。这是可包含零下限的 log1p 显示拉伸。
- **Hist**：以原始、最细 HEALPix 覆盖单元的全局累计分布，在当前上下限内重新归一化做直方图均衡。不是只对当前视窗做均衡。
- 配色：Turbo、Jet、Inferno、Viridis、Magma、Gray，可反转。色条的刻度始终是实际 A_V 数值，颜色随拉伸更新。
- 显示偏好保存在当前浏览器，跨刷新保留；标注存于服务端数据库。

## 网页使用说明与在线统计

使用说明统一放在网站右上角「使用指南」中，含快速开始、绘制与修改、显示与颜色、用户名管理、统计与倾角、导出与备份六个章节；不再单独维护 PDF 手册。顶部项目标注改为「M31 气泡巡天计划」，原始数据来源仍在地图角标和数据说明中保留。

点击顶部「统计图谱」查看当前目录或所有参与者的已保存记录，可按手动分类筛选。图谱包括投影 / 盘面等效直径的对比直方图、尺寸与盘面星系中心距散点图，以及分类数量图。逐条表格提供完整长短径、等效直径、面积、轴比和星系中心距；支持统计 CSV 与独立 SVG 图下载。空目录不填充示例数据，加载失败时不把部分结果当完整统计。

默认 D=780 kpc、i=77°、盘面 PA=38°，中心沿用底图 ICRS TAN 参考点。参数参考 [Zhang et al. 2024, Section 2.3.1](https://arxiv.org/html/2401.01517v1#S2.SS3.SSS1)，可在统计窗口调整。i=0° 表示正面朝向，允许范围 0–85°；PA 从天球北向东计，模 180°。这些统计参数不写回原有椭圆。

**计算口径：薄盘、固定距离、平行投影近似。** 原始 TAN 像素椭圆通过 CD 矩阵和距离 D 转成中心切平面的物理半轴向量；旋转到星系长短轴，沿短轴方向乘 `1/cos(i)`，再用椭圆矩阵的奇异值求盘面长短半轴。中心用同一变换计算 `R=sqrt(X²+Y²)`。天球投影物理尺寸也使用同一中心 TAN 平面和固定距离，作为倾角修正的可比基准。

- `major_pc`、`minor_pc`：完整直径，不是半轴。
- `equivalent_diameter_pc = 2*sqrt(a*b)`：等面积圆直径，a/b 为物理半轴。
- `area_pc2 = pi*a*b`，`axis_ratio = b/a`，`galactocentric_radius_kpc` 为盘面中心距。
- 统计 CSV 同时保存原始角参数、两种物理尺寸口径、D/i/PA；SVG 附带使用的参数和记录数。
- 不把每个方向都统一除以 cos(i)：半轴变化依赖椭圆相对于星系长轴的方向。在本模型中，面积比为 `1/cos(i)`，等效直径比为 `1/sqrt(cos(i))`。

盘面结果**不是球状气泡的真实三维直径**，未建模盘外延伸、翘曲、视线深度差或几何参数误差，也没有完备性修正。所有参与者的重复标注未合并，记录数不能解释为独立气泡数。中位数与直方图描述的是所选目录、分类和参数下的标注样本，不代表全星系气泡总体分布。

## 平滑计时结论

按要求先测计算量；平滑参数约定为高斯核 **sigma（角秒）**，而不是 FWHM。2026-11-25 在本机对 **sigma=3″** 做完整流程计时，设置 60 秒硬上限。使用原始 NSIDE=131072 的稀疏 HEALPix 球面高斯邻域（4 sigma 截断、缺测归一化，不降分辨率），在 60.004 秒停止时完成 3,726,336 / 4,210,860 个单元（88.49%），尚未进行重投影和 PNG 生成。

因此遵照“超过 1 分钟就不平滑”的条件，**本版不加入平滑入口，保持 sigma=0 的原始底图**。这一次结论只对应所测的 3″ 核，不把它推广成所有更小核的耗时结论。

计时证据：`docs/smoothing-benchmark.json`；复现脚本 `scripts/benchmark-smoothing.py`。脚本只写测试输出，不改变原始 FITS 或网站默认底图。直接对 NSIDE=131072 全天天图调用 `healpy.smoothing` 需要处理约 2060 亿个像素，因此没有分配全天天图。

## 坐标与精度

输入：`M31_AV_map_PHAT_PHAST.fits` 的稀疏银道坐标 HEALPix 表，RING，NSIDE=131072，共 4,210,860 行。

显示：转换到以 RA=10.6847083°、Dec=41.26875° 为参考点的 **ICRS TAN** 切平面，显示采样 1.6″/像素。默认把近似长轴方向放水平（显示基准 PA=38°），不做盘面去投影、不拉伸星系、不扣银河前景。可切换北向上或任意旋转。该显示方向是可调的视觉选择，不是对盘面几何的重新测量。

每个显示像素查询其所在原始 HEALPix 单元，不平滑、不插值；无覆盖值保留为空。PNG 的 R/G 通道编码 `round(A_V*1000)`，65535 是无覆盖值，B 通道记录原始有效分辨率。PNG 仅是可实时重新着色的数值显示载体；原始 FITS 仍是科学数值依据。

服务端保存时从同一套 WCS 重新计算：

| 字段 | 含义 |
| --- | --- |
| `ra`, `dec` | 椭圆中心，ICRS，十进制度 |
| `a_arcsec`, `b_arcsec` | 中心局部切平面的长、短**半轴**，角秒；a≥b |
| `pa_deg` | 长轴方位角，天球北为 0°，向东增加，模 180° |
| `pa_defined` | 近圆形时为 false，PA 没有唯一物理意义 |
| `x,y,rx,ry,theta` | 显示 TAN 网格中的几何，0 基像素中心，theta 为弧度 |
| `map_id` | 对应 WCS 与底图版本 |
| `revision` | 同一气泡的修改版本号 |

角尺度和 PA 由投影在中心的局部雅可比和椭圆矩阵计算，已与 Astropy 的独立球面偏移结果核对。旋转视图和改变颜色不会改动天球参数。大的 TAN 平面椭圆在球面上不完全等于一个局部角椭圆，因此 JSON 额外导出 96 个精确变换的边界采样点，保留绘制轮廓；DS9 的局部角椭圆是近似表达。

CSV 导出中心、角秒半轴、PA、分类和备注；JSON 另含 WCS、底图校验和、显示参数与边界；DS9 `.reg` 使用 ICRS，半轴显式标注为角秒，按 Astropy regions 的约定用 `(PA+90) mod 180` 转换 DS9 的角度。导出只包含已确认保存的记录。

原始图的有效分辨率分为约 6.44、3.22、1.61 角秒，不应把 1.6″ 显示采样理解为全图的独立测量分辨率。较粗单元会重复到最细网格。中心约 3′ 内有拥挤影响；PHAST 的双波段区域在绝对消光及细结构方面较不可靠。`av_scatter` 不是地图误差，本工具没有把它当作误差使用。

## 本机运行

作者当前工作目录已安装依赖并初始化本地数据库。在这台 Mac 上可双击 **`启动网站.command`**，然后打开 http://127.0.0.1:5173/ 。本机标注保存在本地数据库中。关闭运行终端或按 Ctrl+C 可停止本机服务器。

从 GitHub 首次安装（Windows、macOS 或 Linux，Node.js ≥22.13，需带 npm）：

```sh
git clone https://github.com/Grapeknight/m31-bubble-atlas.git
cd m31-bubble-atlas
npm ci
npm run dev:local
```

等待终端显示 `http://127.0.0.1:5173/` 后，在同一台电脑的浏览器打开该地址。运行期间保持终端开启；Ctrl+C 停止服务。再次启动运行 `npm run dev:local`。这仅启动本机网站，不会公开部署。

本仓库已包含运行所需的数值底图，不需要下载 96 MB 的 FITS，也不需要 Python 即可标注。首次 `npm ci` 需要联网，安装后的标注和显示计算使用本地资源。macOS 也可以双击 `启动网站.command`；该脚本优先使用作者 Codex 自带 Node，否则使用系统 Node。

若 5173 端口已有本工具运行，启动脚本会提示复用。若被其他程序占用，先停止占用程序，再启动本工具。

`dev:local` 在首次运行时构建并应用本地迁移，之后启动预览；已应用迁移在忽略的 `.sites-runtime/local-migrations.json` 中记录。不要单独删除这个标记而保留旧数据库。完整重建本地测试环境时可以一同移走 `.wrangler/` 和 `.sites-runtime/local-migrations.json`，但这会移走本地标注，需先导出。

本机开发只绑定回环地址。当前使用 Vinext 和 Cloudflare Workers 模拟器，结构化数据用本地 D1 SQLite，尚未部署线上服务。`.openai/hosting.json` 保留了先前准备的托管项目配置，目前未发布；本地验证无需登录托管服务。后续根据实际服务器环境选择部署方式。不要在请求处理中建表。

## 本地数据与备份

用户名、标注与选择会话存放在 `.wrangler/state/v3/d1/` 的 SQLite 数据库中；每次启动保留，不会因刷新网页消失。浏览器中的显示偏好与数据库分开保存。

建议定期从界面导出各用户名的 JSON/CSV 目录。完整备份时先停止服务器，再复制 `.wrangler/` 目录及 `.sites-runtime/local-migrations.json`；恢复时停止服务，成对恢复这些文件，再启动。JSON 是可检查的科学目录导出，目前没有图形界面的批量导入功能。

仓库不上传标注数据库、会话、环境变量、node_modules、构建产物及本机运行缓存。GitHub 公开的是程序与底图资源，后续用户创建的标注保留在运行服务器上。

## 后续部署

目前仅提供经过验证的本地版本，未发布公网网站，也没有自动部署到公网的工作流。源码支持 Vinext / Cloudflare Workers 与 D1；`.openai/hosting.json` 为此前准备的托管配置，并非服务器登录凭证。

部署到普通 Linux 服务器时，需要先确定 Node.js 版本、运行方式、持久数据库位置、域名、HTTPS 和反向代理配置，再适配服务端运行方式。不能只把静态 HTML 上传到静态托管服务，因为用户名和标注保存依赖服务端 API。上线后所有人应访问同一个服务实例或共享数据库，才能看到同一份参与者名单。

## 数据生成、检查与目录

```sh
# 只在需要重新生成显示数据时运行；依赖 numpy astropy healpy pillow
python3 scripts/prepare-map.py --fits /absolute/path/M31_AV_map_PHAT_PHAST.fits

npm test                         # 独立 WCS、半轴、PA、显示变换与颜色拉伸检查
npm run test:api                 # 先启动本地预览；仅允许 localhost，清理自身样本
npx tsc --noEmit
npm run build
```

- `app/workspace.tsx`：主界面、参与者目录、参数面板、导出。
- `components/map-stage.tsx`：缩放、拖绘、平移、旋转手柄。
- `lib/astro.ts`：天球投影与椭圆参数；`lib/renderer.ts`：GPU 重新着色，附 CPU 回退。
- `app/api/profiles/`：无密码用户名选择；`app/api/bubbles/`：按当前用户名保存、按指定用户名浏览。
- `db/schema.ts`、`drizzle/`：数据库表及不可改写的迁移历史。
- `public/map/`：约 4 MB 的原始数值显示纹理、WCS 与全局直方图；不是论文截图。
- `tests/`：Astropy 参考值、数学与本地接口检查。
- `outputs/`：本次本地浏览器验证截图、示例导出和验证摘要，未上传到站点源码。

已完成 16 组坐标/颜色/统计/偏好检查、48 个本地 API 断言和真实 Edge 浏览器端到端验证（绘制、保存、颜色切换、目录浏览、导出、删除与响应式布局）。

重新生成底图需 Python 3.9+ 与 `numpy astropy healpy scipy pillow`。从下列 NADC 页面取得原始 FITS，使用 `--fits` 显式指定路径；默认路径是作者工作目录中的 `../data/M31_AV_map_PHAT_PHAST.fits`。原始 FITS SHA-256：

```text
d69464f83e10699f654f3662a6580aa9c979c3416bbbc1d55c098d6f9438e962
```

更改投影或采样后需重新核验参考值与已保存椭圆使用的 `map_id`，不能把旧目录直接解释为另一幅图的像素坐标。

## 界面语言、分类与用户名长度

- 顶部横幅为「空泡捕手计划 之 仙女座空泡搜寻」，无绿点；窄屏另起一行显示。
- 默认中文；右上角 EN / 中文 切换界面，偏好保存在当前浏览器。用户名、气泡名称和备注保持用户原文，不会被翻译。
- 分类为黄金、白银、青铜；英文依次为 Type A、Type B、Type C。旧记录较可信/候选/待复核兼容映射为黄金/白银/青铜，无需删除旧数据。新记录默认白银。
